## Розгортання (GitHub Pages)

- Після того як ви закоммитите й запушите зміни в гілку `main`, GitHub Actions автоматично запустить воркфлоу, який опублікує вміст репозиторію як статичний сайт на GitHub Pages.
- Перевірити стан деплою можна на вкладці `Actions` репозиторію.
- Публічний URL зазвичай має вигляд: `https://<GitHub-username>.github.io/<repo-name>`.

Якщо потрібна допомога з кастомним доменом або перевіркою після деплою — скажіть, я допоможу.
